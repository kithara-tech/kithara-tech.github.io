# Fontes do site Kithara (protótipos aprovados no Claude, 23/11/2026)

Endereço final: https://kithara-tech.github.io/ (organização GitHub `kithara-tech`, repositório `kithara-tech.github.io`).

Cada .html é um protótipo de página única, autocontido (CSS e JS inline). São a referência visual e de conteúdo; não são para copiar como estão.

| Arquivo | O que é | Vira no site |
|---|---|---|
| site-principal.html | Página principal: abertura com lira, "O que te traz aqui?" (7 caminhos I–VII), sobre/founder, 7 seções de serviço, contato | `/` |
| portfolio.html | Portfólio ao vivo: vídeos do ThanatoFest com filtro, artistas, trecho de "Naquele Banco" | `/portfolio` |
| apresentacao.html | Apresentação completa: formação, instrumentos, voz (teclado SVG), autorais, eventos, ITA | `/apresentacao` |
| material-recorrencias.html | Trilha de estudo de recorrências lineares (MathJax) | `/materiais/recorrencias` |
| material-metodo-estudo.html | Pareto, curva ABC e ciclo de preparação | `/materiais/metodo-de-estudo` |
| linktree.html | Versão linktree antiga (só referência; o `/` substitui) | não vira página |
| kithara-base.css | Tokens e componentes da identidade (Musageta claro / Bronze escuro) | base do design system |

Identidade: Musageta (claro, mármore e ouro) e Bronze (escuro). Fontes Cinzel (títulos/numerais), Cormorant Garamond (subtítulos/serifa), Inter (texto).
Tema: segue o sistema na 1ª visita, botão alterna, escolha salva em localStorage("kth-mode").
